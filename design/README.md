# CommentFX — design canvas

۱۵ صفحهٔ طراحی‌شده روی یک کنواس: اپ موبایل، وب، و جایگزین تم روشن.

## پالت — «اُبسیدین و برنج»

| نقش | تیره | روشن |
|---|---|---|
| زمینه | `#0B0E14` | `#F4F5F8` |
| سطح (کارت) | `#141922` | `#FFFFFF` |
| خط | `#242C3A` | `#E2E6EC` |
| متن اصلی | `#EEF1F6` | `#0F1620` |
| متن ثانویه | `#A8B2C4` | `#3D4A5A` |
| کم‌رنگ | `#6E7A8F` | `#7B8799` |
| اکسنت ۱ (برنج) | `#D9B071` | `#8A6420` |
| اکسنت ۲ (فیروزه‌ای) | `#5FC9C0` | `#1F7E77` |
| رشد | `#3DD68C` | `#0E8A57` |
| ریزش | `#FF6B6B` | `#C93636` |

دو اکسنت عمداً هم‌روشنایی و هم‌اشباع‌اند و فقط در فام فرق دارند.
سبز و قرمز **فقط** برای دادهٔ بازار — هیچ دکمه‌ای سبز نیست.

## تایپوگرافی

- **Vazirmatn** — متن فارسی
- **Manrope** — اعداد، نمادها و نام‌های لاتین؛ همیشه با
  `font-variant-numeric: tabular-nums` و `direction: ltr; unicode-bidi: isolate`
  تا ستون قیمت‌ها در چیدمان RTL نلرزد.

`_common.py` توکن‌ها، آیکون‌های SVG و توابع کمکی را دارد؛ `gen1.py` تا `gen7.py`
فایل‌های `.dc.html` را تولید می‌کنند. برای تغییر یک صفحه، ژنراتور مربوطه را
ویرایش و دوباره اجرا کنید.

همهٔ اعداد داخل طرح‌ها نمونه‌اند.
